# 手机端证书信任图文步骤(iPhone Safari)

1. 手机与主机连接**同一个 Wi-Fi**。
2. Safari 访问 `http://<主机IP>:8080/cert/rootCA.pem`
   (地址与二维码由 `setup_windows.ps1` 在结束时打印;也可用 AirDrop / 数据线把 `certs\rootCA.pem` 传到手机)。
3. 系统提示"已下载描述文件": `设置` 顶部会出现提示 → 点击 → `安装`(需要输入锁屏密码)。
4. `设置 > 通用 > 关于本机 > 证书信任设置` → 找到 mkcert 根证书 → **打开"完全信任"开关**。
   ⚠️ 只安装描述文件而不开"完全信任",Safari 仍会报证书警告。
5. Safari 访问 `https://<主机IP>:8443` → 确认无证书警告 → 允许相机权限。
6. 开始使用: 对准托盘,画面上会出现绿色检测框/ID 与计数。
   - iOS 相机权限可能每次打开页面都重新询问,属正常现象。
   - 建议使用外置稳定光源(LED 面板灯 / 环形灯);iOS 网页大概率无法控制闪光灯。

> 以上为通用 iOS 流程,不同 iOS 版本菜单文字可能略有差异。
